# Log out of the Free Mobile customer area — demo site

Use this skill only when the user's task asks to log out (for example "déconnectez-moi"), or at the
end of a task when the user asked to be logged out afterwards.

## Where
- Any page of http://localhost:8000/account/ when logged in: top right of the red header,
  under the holder's name and line number, the link "Se déconnecter".

## Steps
1. Click "Se déconnecter" in the header.
2. Check that the page shows "Connexion à votre Espace Abonné".
3. Answer that the user is logged out.

## Never (in this task)
- Never click "Réinitialiser la démo" (footer): it erases the demo account's changes; it is not a logout.
- Never log back in unless the task asks for it.
- Never change anything before logging out.
