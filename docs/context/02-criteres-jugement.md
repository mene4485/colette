# 02 — Critères de jugement (officiels)

| Critère | Poids | Ce que ça implique pour nous |
|---|---|---|
| **Use of Computer Use** | 25 % | L'agent H doit être central et visible : navigation réelle sur Free, pas un script. Montrer l'écran. |
| **Technical execution & reliability** | 25 % | Doit marcher de bout en bout, de façon répétable, sans intervention humaine. Répéter la démo ≥ 3 fois avant le pitch. |
| **Usefulness & impact** | 20 % | Vrai problème, vrais utilisateurs (13 M de personnes, 1/3 de renoncement). Chiffres dans le pitch. |
| **Originality & innovation** | 15 % | Voix + computer use + confirmation orale avant action irréversible. Le "coup de fil à quelqu'un de confiance". |
| **UX & user control** | 10 % | L'utilisateur peut superviser (barre d'étapes, narration vocale) et **stopper** l'agent à tout moment. Bouton/mot "stop". |
| **Demo clarity & Q&A** | 5 % | Démo courte, lisible, scénario narré. Préparer les réponses (bots bloqués ? sécurité ? identifiants ? business model ?). |

## Lecture stratégique
- 50 % du score = l'agent computer-use fonctionne de manière fiable. C'est la priorité n°1 du samedi.
- "User control" se gagne presque gratuitement avec : narration par étape + barre de progression + stop vocal + confirmation avant action irréversible.
- Les sponsor tracks (Gladia 1 000 €, Devin 1 000 €) sont à part : utiliser Gladia pour le STT nous rend éligibles.
